 STEP 4 — DEMO FLOW FOR THE JURY (3 Scenarios)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Open http://localhost:8000 and walk through these 3 scenarios:

------------------------------------------------------------
 SCENARIO A: Baseline Flow (Green button)
------------------------------------------------------------
  Click "Baseline Flow"
  
  What to say:
  "This is normal shopping traffic — around 15 to 20 transactions
  per second. You can see all decisions are instantly APPROVED.
  Risk scores stay below 0.05. Zero friction for real shoppers."

------------------------------------------------------------
 SCENARIO B: Flash Sale Surge (Yellow/Orange button)
------------------------------------------------------------
  Click "Flash Sale Surge"
  
  What to say:
  "Volume just jumped to over 130 TPS — that is a 7.5x spike.
  Legacy rule-based systems would panic and start blocking people.
  SurgeGuard keeps approving because the feature vectors still look
  like legitimate shoppers. High volume is NOT the same as fraud.
  Zero false declines. This is our core insight."

------------------------------------------------------------
 SCENARIO C: Coordinated Bot Attack (Red button)
------------------------------------------------------------
  Click "Coordinated Attack"
  
  What to say:
  "Now we have a real bot attack — same high velocity, but now
  the transaction feature vectors are anomalous. V14, V4, V12
  are deviating from normal buyer behavior. The composite risk
  score spikes above 0.80. Watch the HALT badges appear in real
  time. We are quarantining 78% of fraudulent transactions while
  still approving the legitimate shoppers mixed in the traffic."

  After a few seconds, copy one of the HALT transaction IDs
  from the ledger table (the TX-XXXXXX-XXXX string).

  What to say:
  "This is the Admin Override Console. When our engine HALTs or
  flags a transaction for REVIEW, a compliance officer or fraud
  analyst can see all the flagged transactions here in real time.

  Click on any HALT row to open the detail panel.

  What to say:

  "Now that transaction shows as APPROVED in the current status,

Switch back to the Live Dashboard tab using the back arrow
in the admin console header — the dashboard should still be
running with live transactions.

 TROUBLESHOOTING QUICK FIXES
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Problem: Server crashes with "IsolationForest" error
Fix: This was a bug — it has been fixed. Restart the server.
     python run_server.py

Problem: Dashboard goes blank when clicking Admin
Fix: You opened admin.html from file explorer.
     Always use http://localhost:8000 and http://localhost:8000/admin
     Never open files directly from Windows file explorer.

Problem: Admin shows ENGINE: OFFLINE
Fix: The server is not running. Open a terminal and run:
     python run_server.py

Problem: No transactions in Admin panel
Fix: Go to the Dashboard first and run the "Coordinated Attack"
     scenario for 10-15 seconds. The HALT/REVIEW transactions
     will then appear in the Admin panel automatically.

Problem: "ModuleNotFoundError"
Fix: Install missing package:
     pip install fastapi uvicorn lightgbm numpy pandas python-dotenv

Problem: Port already in use
Fix: Another server is running. Find and kill it:
     netstat -ano | findstr :8000
     taskkill /PID <number shown> /F
     Then restart: python run_server.py
